# Shopping Cart
This is a mock shopping cart website project.

## Features:
---
### React Project
- use **vite** to build this project
- props
- *.map* to render list
- *ternary opeartor* and *&& operator* to make conditional rendering
- use **key** for list
- *useState* and *useEffect*
### React testing
tests for all implement, from user angle

- fetch when using(promise, error handling and pending status)
